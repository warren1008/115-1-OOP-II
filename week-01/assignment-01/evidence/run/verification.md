# 登入視窗驗證紀錄

- 日期：2026-11-01（台灣時間）。
- 環境：Windows、JDK 25.0.2、UTF-8。
- 執行者：AI 協助執行；不代表學生本人已手動完成以下操作。
- 依據：本作業題目圖片與 `src/LoginWindow.java`。

## 方法

將兩份 Week 01 主程式及本機暫存驗證工具以 `javac -encoding UTF-8` 編譯，於 Swing 事件派送執行緒建立真實視窗，從元件樹取得輸入欄、按鈕及標籤。登入操作透過已註冊的按鈕事件執行；視窗關閉則以獨立 JVM 派送 `WINDOW_CLOSING`，確認程式以代碼 0 結束。

本機驗證工具位於 `tmp/week01-review-20261101/VerifyWeek01.java`，由根目錄 `.gitignore` 排除，不是作業原始碼的一部分。兩份作業合計通過 947 項斷言。
